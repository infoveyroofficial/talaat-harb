# طلعت حرب باشا — مشروع تاريخي باللغة العربية

موقع عربي متجاوب بالكامل عن محمد طلعت حرب، جاهز للنشر مجانًا على **GitHub Pages** دون تثبيت أي مكتبات أو تشغيل أوامر بناء.

## طريقة النشر (5 خطوات)

1. فك ضغط الملف `talaat-harb-github-ready.zip`.
2. افتح GitHub وأنشئ مستودعًا (Repository) عامًا جديدًا — مثال: `talaat-harb`.
3. اضغط **Add file → Upload files** وارفع **الملفات الأربعة** `index.html` و`journey.html` و`styles.css` و`script.js` من داخل المجلد نفسه (وليس ملف ZIP نفسه)، ثم **Commit changes**.
4. من **Settings → Pages → Build and deployment** اختر **Deploy from a branch**، ثم `main` والمجلد `/(root)`، واضغط **Save**.
5. افتح الرابط الذي ستعرضه GitHub Pages، غالبًا `https://YOUR-USERNAME.github.io/talaat-harb/`.

> مهم: لا ترفع المجلد الكامل داخل مجلد آخر في المستودع؛ يجب أن يكون ملف `index.html` في جذر المستودع. الصور التاريخية تُحمّل من Wikimedia Commons عبر الإنترنت، والخطوط تُحمّل من Google Fonts عند الاتصال بالإنترنت، بينما المحتوى والواجهة لا يحتاجان إلى خادم.

## المحتويات
- `index.html`: الرئيسية والسيرة والإنجازات والتذييل.
- `journey.html`: خط الحياة الزمني، الأسرة، المقالات الكاملة، والمراجع.
- `styles.css`: التصميم العربي الأنيق والتوافق مع الهاتف.
- `script.js`: صورة الركن المتحركة، مؤشر القراءة، القائمة، وحوارات المقالات.

## الملحوظات التاريخية
تتفاوت المصادر بشأن ما إذا كان طلعت حرب قد أنجب ابنًا ذكرًا؛ ولذلك عُرض هذا الاختلاف في صفحة الأسرة بدل تقديم رواية واحدة كحقيقة قطعية. وكذلك يوجد اختلاف في بعض المصادر بشأن يوم الوفاة، واعتمد الموقع اليوم الوارد في مصدر «ذاكرة مصر المعاصرة».

المشروع مُعد باسم **3 E – مروان محمد منير**.
